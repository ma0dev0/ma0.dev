# ma0 tools / Cinematic UI・UX

確認日: 2026-09-10

## 目標

「その手間に、小さな魔法を。」というメッセージを、読むだけでなく動きで感じられるプロダクトストーリーをつくります。大きな日本語のタイポグラフィ、立体的なツール画面、短いスクロール連動シーン、明暗を切り替える作品ギャラリーを組み合わせています。

## デザインと操作

- ヒーロー: 3つのガラス風ツールウィンドウと、奥行きを投影した粒子リング。マウス移動に反応し、押すとリングが広がって戻ります。
- ストーリー: 散らばった粒子が `ma0 → 猫の手 → OSS` に変形。スクロールを戻すと同じ位置へ戻ります。
- 作品: 明るい背景と大きな紹介カード。製品名に続けてメリットを示し、先頭作品は説明を左、使用イメージを右に配置します。スマートフォンでは縦に並びます。ツールと音楽を絞り込めます。
- メーターとリンク集の使用イメージはHTML/CSSで描き、拡大時も文字と図形を鮮明に保ちます。日本語の字間とストーリー見出しのサイズを調整し、本文と粒子が競合しないようにしています。
- About / Contact: 大きな見出しと余白で、制作方針や連絡先を伝えます。
- ツールウィンドウと42%表示は使用イメージです。実際の使用量や製品画面を示すものではなく、その旨を画面下に明記しています。
- キーボード検索、深いリンク、章ナビ、メールコピーは維持しています。

見せ方の参考: [AppleのiPhoneページ](https://www.apple.com/iphone/)。コピーや画像を流用せず、ma0 toolsのテーマとコンテンツで実装しています。

## 動きの制御

`motion.js` に描画処理を分離しました。

- ヒーローは30fpsを上限に、モバイル900粒子・デスクトップ1,800粒子を描画。
- DPRは最大1.5。画面外・非表示タブでは描画ループを停止。
- ストーリーはスクロール・リサイズ時だけ描画。停止した状態でループを回し続けません。
- ユーザーが「動きを止める」を選ぶと、すべてのストーリーを通常の文章として表示します。選択はそのタブのセッション中保存します。
- OSのreduced-motion、Save-Dataでも静的な構成になります。表示中の設定変更にも対応。
- JavaScriptがなくてもCSSの静的ビジュアル、すべての文章、作品へのリンクを表示します。

## 検証

- Playwright: 14項目。既存の11項目に、動画的な描画の開始・停止・再開、スクロール巻き戻しの一致、表示中のreduced-motion切り替えを追加。
- 幅320〜1440px、日英、200% CSS拡大、深いリンク、検索、作品絞り込み、コピー成功・失敗、JavaScript無効を確認。
- 全6ページのHTML・ARIA検証、ローカル参照とJavaScript構文を検証。
- axe-core 4.13.0で全6ページのWCAG 2 A / AA、2.1 AAを自動検査。検索ダイアログも確認。
- デスクトップ、スマートフォン、ストーリー途中、作品エリアをブラウザーで確認。アプリ内ブラウザーでもスクロールを操作。

操作検証はChromium中心です。Safari・Firefoxの実機検証、支援技術との完全な適合確認、本番CDN上の実ユーザー測定は含みません。

## 同条件測定（前段のアニメーション再設計時）

この数値は `73cb91c` にまとめたアニメーション再設計時の測定です。今回の作品プレビュー・文字組みの追加調整後は再測定していません。

比較元は初期のアニメーション版 `836c74c`。新旧ともローカル配信、390×844、DPR 1、CPU 4倍スローダウン、下り200,000 B/s・上り100,000 B/s・遅延40ms。外部フォントの変動を除くためGoogle Fontsをブロックし、各3回を新しいコンテキストで測定しました。中央値を記載します。

| 指標 | 初期版 | アニメーション再設計時 |
| --- | ---: | ---: |
| メインスレッド処理時間 | 2,001 ms | 762 ms |
| LCP | 760 ms | 540 ms |
| CLS | 0.00441 | 0.00170 |
| 観測リソース転送量 | 116,831 B | 164,662 B |
| 先頭から作品までの距離 | 5,491 px | 2,701 px |

この測定ではアニメーションを残し、初期版に比べメインスレッド処理時間を約62%削減しています。静的なページよりも描画処理は必要ですが、視覚表現と操作体験を優先し、描画頻度・粒子数・表示範囲で負荷を制御しました。

TaskDurationはloadから3秒間観測後の値、転送量はHTMLを除くResource Timing合計です。LCPは主に見出しの表示を測っており、粒子の品質やフレームレートを表すものではありません。測定後の字幕・アクセシビリティ・重なり順の微調整により最終ファイルの転送量にはわずかな差があります。

生データ: [uiux-benchmark.json](uiux-benchmark.json)。再実行は初期版を4322、今回の版を4321で起動し、`node scripts/benchmark.cjs` を使用します。
