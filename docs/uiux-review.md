# ma0 tools UI/UX刷新レポート

確認日: 2026-09-10

## 設定したゴール

初めて訪れた人に、何を作っているかが最初の画面で伝わり、気になった作品へすぐ進めること。生成画像による独自性と、読める・操作できる・軽く動くことを両立する「小さなOSSのアトリエ」を目指しました。

## 変更内容

- チャコール、オフホワイト、ライムを軸に、日本語・英語・リンク集を統一。
- 「Small tools. More possibilities.」と日本語の説明、作品への直接リンクを冒頭に配置。
- 独自のガラス彫刻を画像生成し、プロジェクト内にWebPとして保存。主画像1536×1024、モバイル版800×533。画像内の文字は使わず、見出しとボタンはHTMLで実装。
- 長いスクロール連動ストーリーを3つの短い原則に変更。
- 作品は「すべて／ツール／音楽」で絞り込み。選択状態と件数を読み上げにも通知。
- 既存の公開中2作品と準備中1作品の区別、実際のリンク先を維持。
- 章の現在地、深いリンク、検索ショートカット、メールコピーを維持。検索は日本語の「作品」「連絡」などにも対応。
- キーボードのフォーカス、検索結果なし、コピー失敗、JavaScript無効、reduced-motion、Save-Data、拡大表示への対応を追加・改善。
- 常時稼働するWebGL、Canvas、カスタムカーソル、文字シャッフルを撤去。短い登場・ホバー演出に整理。

## 検証

- `python3 scripts/verify_site.py`: 全6ページ、ローカル参照、日英の構造、JavaScript構文を確認。
- `html-validate@11.10.0`: 全6ページでエラーなし。
- Playwright: 11テスト通過。幅320 / 375 / 760 / 761 / 1180 / 1181 / 1440px、日英、章ナビ、深いリンク、検索、絞り込み、コピー成功・失敗、JS無効、Save-Data、200% CSS拡大を検証。
- axe-core 4.13.0: 全6ページでWCAG 2 A / AAおよび2.1 AAの自動検査に違反なし。検索ダイアログも確認。
- 実画面: デスクトップ1440px、スマートフォン390pxでヒーロー、作品、ページ全体のスクリーンショットを確認。agent-browserで絞り込みも操作。

自動検査の合格は、すべての障害や支援技術への完全適合を保証するものではありません。今回の操作検証はChromiumです。Safari・Firefoxの実機検証と本番配信での速度測定は未実施です。

## 同条件での変更前後測定

比較元: `836c74c`。新旧を別のローカルサーバーで配信し、それぞれ新しいブラウザーコンテキストで3回測定しました。以下は中央値です。

| 指標 | 変更前 | 変更後 |
| --- | ---: | ---: |
| メインスレッド処理時間 | 2,016 ms | 123 ms |
| LCP（主要コンテンツの描画完了） | 760 ms | 908 ms |
| CLS（予期しないレイアウト移動） | 0.00441 | 0.00163 |
| 観測したリソース転送量 | 116,831 B | 192,137 B |
| ページ先頭から作品までの距離 | 5,491 px | 1,328 px |

メインスレッド処理時間は約94%減少し、作品までの距離は約76%短縮しました。一方、生成画像を追加したため転送量が増え、LCPは148ms増加しました。画像の印象と軽さのバランスとしてモバイルには約56KBの画像を配信しています。「すべてが高速化した」という結果ではありません。

測定条件: Chromium、390×844px、DPR 1、CPU 4倍スローダウン、下り200,000 B/s、上り100,000 B/s、遅延40ms。外部フォントのネットワーク変動を除くため、両方ともGoogle Fontsをブロック。ページのloadから3秒間観測し、TaskDurationを取得。転送量は観測時間内のResource Timingの合計（HTML本文を含まない）です。先に変更前3回、次に変更後3回の順で測定しました。

ローカルの合成測定であり、実際のユーザーの回線や端末、本番CDNでの値とは異なります。検索キーワードと読み上げ文言の最終微調整前に測定したため、最終版のテキスト転送量には数百バイト程度の差があります。

生データ: [uiux-benchmark.json](uiux-benchmark.json)
